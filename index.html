OPC UA Server (IEC 62541)

Embedded standard OPC UA Server listening on port 4840. Exposes virtual Arduino variables as industrial nodes under the FactoryIO_Device root for automatic driver discovery.

Modbus TCP Server

High-speed industrial Modbus TCP server on port 502/8502. Native mapping of Discrete Inputs, Coils, Input Registers, and Holding Registers for Factory I/O drivers.

⚙️ Factory I/O · OPC UA Client

Configure Factory I/O driver in 3 easy steps:

  • Press F4 → Driver: OPC UA Client
  • Configuration:
    Server: opc.tcp://127.0.0.1:4840
    Security: None / Anonymous
  • Click Connect (green dot indicator).
  • Tags automatically appear under FactoryIO_Device.
🏭 Factory I/O · Modbus TCP

For ultra-fast low overhead communication (Full Plan):

  • Press F4 → Driver: Modbus TCP/IP Client
  • Configuration:
    Host: 127.0.0.1 · Port: 502 / 8502
    Slave ID: 1 · Coils / Discretes
  • Sensors → Drag onto Coil 0, 1...
  • Motors → Drag onto Discrete Input 0, 1...
💻 CODESYS / TIA Portal SCADA

Integrate simulated Arduino as an industrial data source:

  • Add an OPC UA Data Source Manager in CODESYS.
  • Set Endpoint URL:
    opc.tcp://127.0.0.1:4840
  • Browse and bind variables to your IEC 61131-3 PLC variables.
